# MaxBuild Infrastructure

Premium construction company website + Admin CMS built with React 19, Vite, Tailwind CSS, Framer Motion, Lenis, and Zustand.

## Getting started

```bash
npm install
npm run dev
```

## Public site

`http://localhost:5173/`

## Admin CMS

| | |
|---|---|
| URL | `http://localhost:5173/admin` |
| Username | `admin` |
| Password | `Pass@123` |

CMS data (projects, services, team, settings) persists in LocalStorage and updates the public site live.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview production build
